## 🇺🇸 English Version

### 👨‍💻 About Me

- 🔭 Currently, I am a **.NET Software Engineer** focusing on building core Class Libraries, automation software, and high-performance Desktop applications.
- 🌱 My passion lies in software architecture (**Clean Architecture**, **SOLID Principles**, **Design Patterns**) to write maintainable and scalable source code.
- ⚡ **Specialized Expertise:** Direct software-to-hardware communication (Kiosks, NI DAQ measurement devices, biometric modules) & 3D CAD drawing automation (SolidWorks API).
- 💬 Ask me about: **C#, WPF (XAML/MVVM), .NET Core API, SQLite, Multithreading, Interop C/C++ DLLs.**
- 🎯 **Goal:** To become a Software Architect / Tech Lead building core industrial systems.

### 🔥 Highlighted Technical Projects

*Instead of standard web CRUD applications, my strengths lie in handling complex logic, interacting directly with hardware and CAD systems.*

#### 1. Enterprise CAD 3D Design Automation (SolidWorks C# Macro) ⚙️
> *Enterprise-grade software system that fully automates the 3D modeling and Bill of Materials (BOM) extraction process for industrial gates and fences.*
* **Architecture Design:** Strictly applied **Clean Architecture**, clearly separating API Communication, Data Models, and Core CAD Processing layers.
* **Algorithms & Patterns:** Utilized **Strategy Pattern** and **Factory Pattern** to flexibly handle complex spatial geometry logic and automatic shaping (Extrude, Weldment) based on customized configurations.

#### 2. Smart Locker Kiosk System (MHA Project) 🗄️
> *Touch-screen Kiosk control software, operating reliably offline (Offline-first).*
* **Hardware Interop:** Directly interacted with microcontroller boards (DCDZ driver) and fingerprint scanners via native libraries (C/C++ DLL).
* **Data Flow:** Built an ultra-durable **SQLite (EF Core)** local database to track internal transactions safely. Configured **MQTT** protocol for real-time device state synchronization.
* **UI/UX:** Modern WPF interface integrated with Material Design effects.

#### 3. High-Frequency Signal Acquisition Software (NI DAQ) 📈
> *Real-time dashboard collecting industrial data.*
* **Multithreading:** Handled massive continuous data streams pushed from National Instruments hardware.
* **Performance Optimization:** Perfect memory lifecycle management in C#, rendering charts (DevExpress) running continuously for days without crashing or lagging.

## 🇻🇳 Phiên Bản Tiếng Việt

### 👨‍💻 Về bản thân tôi

- 🔭 Hiện tại, tôi đang là một **.NET Software Engineer**, tập trung vào việc xây dựng các Class Library lõi, phần mềm tự động hóa và ứng dụng Desktop hiệu năng cao.
- 🌱 Đam mê của tôi là kiến trúc phần mềm (**Clean Architecture**, **SOLID Principles**, **Design Patterns**) để tạo ra source code dễ bảo trì và mở rộng.
- ⚡ **Chuyên môn đặc thù:** Giao tiếp trực tiếp giữa phần mềm và phần cứng (Kiosk, thiết bị đo lường NI DAQ, module sinh trắc học) & Lập trình tự động hóa bản vẽ 3D (SolidWorks API).
- 💬 Hãy hỏi tôi về: **C#, WPF (XAML/MVVM), .NET Core API, SQLite, Multithreading, Interop C/C++ DLLs.**
- 🎯 **Mục tiêu:** Trở thành Software Architect / Tech Lead xây dựng các hệ thống lõi trong công nghiệp.

### 🔥 Các Dự Án Nổi Bật Kỹ Thuật

*Thay vì các dự án web thông thường, thế mạnh của tôi nằm ở việc xử lý logic phức tạp, làm việc trực tiếp với phần cứng và CAD.*

#### 1. Hệ Thống Tự Động Hóa Thiết Kế 3D CAD (SolidWorks C# Macro) ⚙️
> *Hệ thống phần mềm cấp doanh nghiệp giúp tự động hóa hoàn toàn quy trình xuất bản vẽ 3D và bóc tách vật tư (BOM) cho cổng, hàng rào.*
* **Thiết kế Kiến trúc:** Áp dụng triệt để **Clean Architecture**, phân tách rõ ràng tầng Giao tiếp API, Mô hình dữ liệu và Lõi xử lý CAD.
* **Thuật toán & Patterns:** Sử dụng **Strategy Pattern** và **Factory Pattern** để xử lý linh hoạt các logic hình học không gian phức tạp và tạo hình tự động (Extrude, Weldment) dựa trên cấu hình tùy biến.

#### 2. Kiosk Tủ Khóa Thông Minh (MHA Smart Locker) 🗄️
> *Phần mềm điều khiển thiết bị Kiosk màn hình cảm ứng, hoạt động ổn định không cần mạng (Offline-first).*
* **Giao tiếp phần cứng:** Trực tiếp tương tác với board mạch vi điều khiển (DCDZ driver) và máy quét vân tay thông qua thư viện native (C/C++ DLL).
* **Luồng dữ liệu:** Xây dựng cơ sở dữ liệu **SQLite (EF Core)** cực kỳ bền bỉ để lưu vết giao dịch nội bộ. Thiết lập giao thức **MQTT** đồng bộ trạng thái thiết bị thời gian thực.
* **UI/UX:** Giao diện WPF hiện đại tích hợp hiệu ứng Material Design.

#### 3. Phần Mềm Thu Thập Tín Hiệu Tần Số Cao (NI DAQ) 📈
> *Dashboard thời gian thực thu thập dữ liệu công nghiệp.*
* **Xử lý đa luồng (Multithreading):** Xử lý luồng dữ liệu khổng lồ đẩy về liên tục từ phần cứng National Instruments.
* **Tối ưu hiệu năng:** Quản lý vòng đời bộ nhớ hoàn hảo trong C#, render biểu đồ (DevExpress) chạy liên tục nhiều ngày không bị crash hay giật lag.
